    Automate Appian.
    Faster. Reliably.

    Common framework capabilities

    robo-appian includes the common browser lifecycle, pytest integration, correlation, logging, performance instrumentation, and action-snapshot capabilities supplied by robo-automation, exposed through the Appian-facing framework boundary. See Common Framework Features for the complete capability map and usage guidance.
