# Appian Date

Use `AppianDate` for Appian date fields.

```python
page.date(label="Required Award Date").fill("10/07/2026")
```

Date fields share the standard textbox operations, including `fill()`, `clear()`, `click()`, `value()`, `is_visible()`, `is_enabled()`, `is_disabled()`, and `wait_until_ready()`.
